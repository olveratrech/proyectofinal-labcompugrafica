# Manual de usuario

1. Ejecuta `build/laboratorio` desde el repositorio o `Abrir.command` del paquete.
2. Entra por la abertura central de la fachada con W; usa el botón derecho para mirar.
3. Pulsa 1–7 para colocarte frente a cada aparato. WASD permite seguir recorriendo.
4. Haz clic en la hoja sobre la mesa para consultar la explicación. También puedes
   pulsar E cuando estés cerca. Un clic o Esc cierra la ficha.
5. Espacio inicia o pausa las demostraciones; R devuelve sus condiciones iniciales.
   C selecciona otra configuración y reinicia las simulaciones. Estos controles
   afectan al conjunto del laboratorio. La ventana indica el estado y configuración.
6. En la ficha del microscopio, M alterna la ilustración de muestra.
7. Esc, sin una ficha abierta, cierra la aplicación.

La esfera del Van de Graaff responde de forma gradual al encendido y apagado.
Benceno y microscopio son exhibiciones estáticas con fichas interactivas.
No se necesitan Blender ni Python para ejecutar el laboratorio.

Si faltan recursos, comprueba que `assets` y `shaders` estén junto al ejecutable
empaquetado, o que estés ejecutando desde la raíz del proyecto. La compilación local
requiere las bibliotecas de Homebrew descritas en README.
